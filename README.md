# GaffaPythonExamples

Python examples from the [Gaffa](https://gaffa.dev) blog, showing how to use the Gaffa API for scraping, browser automation, and web data extraction. Each example has its own README with setup and run instructions.

## Examples

| Example | Description |
|---|---|
| [Webpage to Markdown](scripts/WebpageToMarkdown/README.md) | A simple CLI tool that converts any web page into LLM-ready markdown. |
| [Scrape Every Image from a Website](scripts/ScrapeAllImages/README.md) | Maps every page on a site, then finds and downloads all of its images. |
| [Scrape a Table with Python](scripts/ScrapingTables/README.md) | Turns HTML tables into structured data with `parse_table`, or captures the DOM to parse yourself. |
| [Automated Form Filling](scripts/AutomatedFormFilling/README.md) | Extracts a form's fields with `parse_json`, then fills and submits it in a real browser. |
| [Downloading Files](scripts/DownloadingFiles/README.md) | Downloads files whether they save directly, render inline, or appear after submitting a form. |
| [Scrape Twitter without Authentication](scripts/ScrapeX/ReadMe.md) | Scrapes tweet text, publish times, and engagement counts from a public X profile, with no login. |
